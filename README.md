# The Shlyapa

Командная игра на объяснение и угадывание слов на время. Телефон передают по кругу: объясняющий видит слово, остальные угадывают.

Одни и те же слова играют во всех раундах. Побеждает команда, у которой больше угаданных слов.

## Как играть

Нужны две команды или больше. В каждой есть объясняющий, остальные угадывают. Хватит и пар.

1. **Набор.** Слова берутся из словаря или каждый вписывает свои: обычно нарицательные существительные в именительном падеже. Бумажки перемешиваются.
2. **Ход.** Телефон у объясняющего, экран не показывают. За 20–60 секунд нужно вытащить как можно больше слов. Угадали — балл команде. Не угадали — слово возвращается в шляпу. Когда шляпа пустеет, раунд окончен.
3. **Три раунда.** Одни и те же слова, разные правила:
   - **Словами.** Можно говорить что угодно, кроме однокоренных, перевода, частей слова, созвучий, рифм и жестов.
   - **Пантомима.** Жесты и мимика. Без слов, звуков и букв.
   - **Одно слово.** Только одна ассоциация, без пояснений.

Партия идёт по экранам: дом, правила, набор команд, запись слов, готовность, ход, итог хода, итог раунда, финал.

## Запуск

```bash
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

| Команда          | Что делает                                                                         |
| ---------------- | ---------------------------------------------------------------------------------- |
| `npm start`      | Сервер разработки на `http://localhost:3000`                                       |
| `npm test`       | Тесты                                                                              |
| `npm run build`  | Сборка в `build`                                                                   |
| `npm run deploy` | Сборка и публикация на [GitHub Pages](https://teslachinator.github.io/the-shlyapa) |

На телефоне игру можно открыть без рамок браузера: в Safari — «Поделиться» → «На экран Домой», в Chrome — «Добавить на главный экран».

## Словари

В партии используются файлы из `public/dictionaries/`:

| Файл         | Набор                   |
| ------------ | ----------------------- |
| `novice.txt` | Новички — бытовые слова |
| `easy.txt`   | Лёгкие                  |
| `medium.txt` | Средние                 |
| `rare.txt`   | Редкие                  |
| `hard.txt`   | Сложные                 |
| `stars.txt`  | Знаменитости            |
| `hype.txt`   | Хайп                    |

Исходные и исследовательские списки лежат в `words/`. Их состав описан в [words/README.md](words/README.md).
